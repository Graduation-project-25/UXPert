# ✨ Figma UX Review Assistant

An intelligent Figma plugin that evaluates UI designs using established UX heuristics and principles. It delivers real-time feedback, AI-generated suggestions powered by GPT-4o, and visually enhanced alternatives via GPT-image-1—all seamlessly integrated within Figma.



## 🚀 Features

- **🔧 Component-Based Architecture**  
  Modular and scalable system enabling clean separation of concerns, easy maintenance, and extensibility.

- **🧠 Heuristic Evaluation**  
  Implements Nielsen’s 10 Usability Heuristics and Gestalt principles to assess design quality.

- **🤖 AI-Powered Suggestions**  
  Context-aware text feedback and actionable suggestions generated by GPT-4o.

- **🖼 Visual Design Enhancements**  
  Design suggestions are visually rendered using GPT-image-1 for easy comparison and implementation.


## 🛠 Tech Stack

| Layer                     | Technologies                             |

| Frontend (Plugin UI)     | TypeScript, HTML/CSS, Figma Plugin API   |
| Backend (Evaluation)     | Python (FastAPI or Flask)                |
| AI Services              | OpenAI GPT-4o, GPT-image-1               |
| Clustering & Preprocessing | Scikit-learn (DBSCAN), NumPy, Pandas  |

| UX Rules Engine          | Custom logic for Nielsen heuristics      |

## 🧠 How It Works
1. Feature Extraction – Gathers layout, color, and positioning info from your Figma design.
2. Heuristic Evaluation – Runs checks based on UX best practices.
3. Feedback Generation – Generates actionable insights on each design frame.
4. AI Suggestions – GPT-4o suggests improvements; GPT-image-1 renders them visually.
5. Display in Figma – All feedback and visuals are shown in the plugin interface.
